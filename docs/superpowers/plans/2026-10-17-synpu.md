# Synpu — PC Durum Paneli: Uygulama Planı

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** PC'de çalışan minik yerel sunucu; aynı ağdaki telefondan açılan tek sayfalık panelle anlık CPU/GPU/RAM/FPS değerlerini gösteren; çoklu PC destekli, QR ile bağlanan, sessiz yönetici olarak otomatik başlayan açık kaynak Windows uygulaması.

**Architecture:** Python 3.12 (uv ile) — FastAPI + WebSocket sunucusu 0.0.0.0:8787'de; veri toplayıcı psutil (CPU/RAM), pynvml (GPU), pythonnet+LibreHardwareMonitorLib (CPU sıcaklığı), PresentMon alt süreci (FPS) kullanır. Tkinter tabanlı QR penceresi + pystray tepsi simgesi. Tek HTML sayfası (derleme adımı yok) WebSocket'e bağlanır, kopunca poll'a düşer. Kurulum: setup.bat → PowerShell betiği (uv, bağımlılıklar, presentmon + LHM indirme, güvenlik duvarı, Görev Zamanlayıcı).

**Tech Stack:** Python 3.12, FastAPI, uvicorn, psutil, nvidia-ml-py (pynvml), pythonnet, qrcode[pil], pystray, Pillow; pytest + httpx (test); PresentMon 2.6.0 console exe; LibreHardwareMonitorLib 0.9.6 (net472 zip).

**Spec:** `docs/superpowers/specs/2026-10-17-synpu-design.md`

## Global Constraints

- Windows 10/11 x64, NVIDIA GPU hedef; CPU sıcaklığı ve FPS için yönetici hakları gerekir; uygulama Görev Zamanlayıcı ile "en yüksek yetkiyle" sessiz başlar.
- Python **3.12** (uv yönetimli), `src/` layout, editable install; paket adı `synpu`.
- Sunucu `0.0.0.0:8787` üzerinde dinler (env `SYNPU_PORT` ile geçersiz kılınabilir).
- Yalnızca anlık değerler; grafik/geçmiş yok. Eksik değer JSON'da `null`, arayüzde "—".
- Kimlik doğrulama yok; erişim yalnızca özel ağ kaynaklarıyla sınırlı CORS/Origin politikasıyla korunur.
- Arayüz dili Türkçe; koyu tema.
- Çalışma zamanında internet gerekmez; yalnızca ilk kurulum indirme yapar.
- Sabitlenmiş dış araçlar: PresentMon **v2.6.0** (`PresentMon-2.6.0-x64.exe`), LibreHardwareMonitor **v0.9.6** (`LibreHardwareMonitor.zip`, net472).
- Aynı port için ikinci çalıştırma çökmemeli; düzgün hata mesajıyla çıkmalı.

## Review Focus

1. NVIDIA'sı olmayan / sürücüsü kırık PC → GPU kartı "—" gösterir, uygulama çökmez.
2. Sensörü desteklenmeyen anakart veya yönetici olmayan çalıştırma → CPU sıcaklığı `null`, diğer değerler çalışmaya devam eder.
3. Oyun yokken arka planda kare sunan süreçler (dwm.exe, tarayıcı, explorer) → FPS "—" kalmalı; saçma değer gösterilmemeli.
4. VPN/sanal adaptör varken QR yanlış adres gösterirse telefon erişemez → birincil adres varsayılan rota arayüzünden seçilir, alternatifler listelenir.
5. Aynı ağdaki genel/özel olmayan kaynaklardan gelen istekler → engellenir; özel IP + portlu kaynaklar → kabul edilir.
